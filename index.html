Install it

This early-access version is installed manually while the Chrome Web Store review is underway.

  1. Click Download the extension above.
  2. Unzip the downloaded tell-jack-you-applied-v0.7.0.zip file.
  3. Open chrome://extensions in Chrome (or the equivalent extensions page in Edge).
  4. Turn on Developer mode.
  5. Click Load unpacked and select the unzipped extension folder.
  6. You're ready. The extension will watch for likely application confirmation pages.
Privacy: detection happens locally in your browser. The extension does not send job-page content to an external server.

What happens after installation?

After I submit an application

On a likely confirmation page, you'll see “✨ Tell Jack?” Choose “Yes, tell Jack” to save the application locally.

When I open Jack & Jill

If you have saved applications waiting, the extension asks “✨ Update Jack about what you've been up to?” Choose “Yes, update Jack”.

Does it need my Jack password?

No. The extension works with the Jack & Jill page you are already logged into and uses the visible chat interface.

What if I don't want to tell Jack yet?

Choose “Not now”. Your saved applications stay queued locally until you decide to update Jack.
